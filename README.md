# 기능상속 (Gineung Sangsok)

> 사라지는 지역 생활서비스를 기존 자원에 이어주는 AI 지역상생 서비스
> 2026 AI 라이프 솔루션 챌린지 출품 프로토타입

**시연 주소:** https://chojeongbin0308-ops.github.io/gineung/

농촌의 가게 하나가 문을 닫으면 판매점 하나만 사라지는 것이 아니라, 주민이 이용하던 여러 생활기능(생필품·신선식품 구매, 공동수령, 마을 거점 등)이 함께 사라집니다. 기능상속은 폐업 **전에** 그 가게의 역할을 생활기능 단위로 나누고, 주변에 이미 운영 중인 자원(이동장터, 농협·마트 배송, 마을회관, 복지기관 등)의 조합으로 이어받을 방안을 제안합니다.

> ⚠️ 시연 지역은 전북 전주 일대입니다. 지도 위의 마을·업체·운영정보는 모두 예시 데이터이며 실제 기관과 무관합니다.

## AI 접근 방법

1. **생활기능 분리** — 판매품목·역할을 생활기능 분류체계(생필품, 신선식품, 무거운 상품, 급한 소량 구매, 농약·비료, 종자·농자재, 방제 상담, 공동수령, 생활거점)에 대응시키고, 65세 이상 비율과 자가용 없는 가구 비율로 기능별 중요도를 보정합니다.
2. **적합도 계산** — `적합도 = 자원 역량 × 주민 접근성 × 운영빈도 충족도`. 거리뿐 아니라 배송 가능 여부, 운영 요일, 이동수단을 함께 봅니다. 인허가가 필요한 품목(예: 농약)은 자격이 없는 자원에서 제외합니다.
3. **조합 최적화** — 기능별 상위 후보와 ‘공백’ 선택지의 모든 조합을 비교합니다. 목적함수는 가중 유지율에서 신규 조치·참여기관 부담을 뺀 값이며, 한 기관의 조정으로 여러 기능을 잇는 조합이 유리해집니다. 상위 3안을 제시합니다.
4. **공백 경보** — 적합도 45 미만인 기능은 기존 자원으로 잇기 어려운 것으로 보고 신규 지원 검토 대상으로 넘깁니다.
5. **유통망 상속** — 공급 경로를 표준 형식(`gineung.supply-card/0.1`, JSON)으로 기록하고, 자격 보유 × 품목 적합 × 거리로 이어받을 곳을 추천하며 따라하기 안내서를 생성합니다.

AI는 제안만 하며, 최종 결정은 지자체 담당자가 합니다.

## 실제 지도와 GPS

- 지도: [Leaflet](https://leafletjs.com/) + OpenStreetMap 타일 (키 없음, 무료). 예시 마을·자원을 전주시청 부근을 기준으로 실제 좌표에 배치합니다.
- **내 위치로 주변 자원 찾기:** 브라우저 위치 권한(GPS)으로 현재 위치를 받아 가까운 생활자원을 실제 거리(하버사인 공식)로 정렬하고, 가장 가까운 예시 가게의 폐업 시나리오 분석으로 바로 이동합니다. 위치 정보는 기기 안에서만 쓰이고 저장·전송되지 않습니다.
- claude.ai 등 외부 연결이 막힌 환경에서는 자동으로 그림 지도로 바뀝니다.

## AI 상담 (시연 모드 / 서버 연결)

- **시연 모드(기본):** 브라우저 안에서 질문의 의도(구매 방법·상속안·공백·자원·유통망·자격·절차)와 품목·가게를 인식하고, 위 분석 엔진의 계산 결과로 답합니다. 서버가 필요 없습니다.
- **서버 연결:** AI 상담 페이지의 ‘모델 서버 연결 설정’에 주소를 넣으면 아래 형식으로 요청합니다. 연결에 실패하면 시연 모드로 답합니다.

```http
POST {서버 주소}
Content-Type: application/json

{
  "model": "gineung-v1",
  "messages": [
    {"role": "system", "content": "현재 분석 데이터 …"},
    {"role": "user", "content": "상리상회 상속안 추천해 줘"}
  ]
}
```

응답은 OpenAI 호환 형식(`{"choices":[{"message":{"content":"…"}}]}`) 또는 `{"answer":"…"}` 중 하나를 받습니다. 서버는 HTTPS와 CORS 허용이 필요합니다.

## 법령 관련 안내

유통망 노트의 농약 관련 안내는 다음을 요약한 것이며, 세부 요건은 관할 기관 확인이 필요합니다.

- 농약판매업은 업소 소재지 관할 시장·군수·구청장에게 등록하고 판매관리인을 지정 (농약관리법 제3조)
- 판매관리인은 농촌진흥청이 실시하는 안전사용·취급제한 교육 이수 (농약관리법 제23조)
- 농약 판매 시 구매자 인적사항·사용 작물·판매 농약을 기록하고 3년 보관, 50ml(g) 이하 소포장 제외 (농약 판매기록제, 2020년 전산화 시행)

## 한계 및 개선 방향

- 현재 데이터는 가상 지역의 예시 값입니다. 실제 적용 시 공공데이터(소상공인 상가정보, 농협 사업장, 이동장터 노선 등)와 지자체 확인 정보로 교체해야 합니다.
- 시연 모드 상담은 규칙 기반이므로 표현이 크게 다르면 이해하지 못할 수 있습니다. 학습된 모델 서버 연동 구조는 구현되어 있습니다.
- 유통망 기록은 브라우저에만 머무르며, JSON으로 내보낼 수 있습니다. 공유 저장소 연동은 향후 과제입니다.
