# 이전 버전 백업

수정 과정의 주요 버전을 그대로 보관합니다. 브라우저로 열면 그 시점의 화면을 볼 수 있습니다.
최신 버전은 저장소 루트의 `index.html`이며, 이후 변경은 모두 커밋 기록과 태그(`v8`, `v9` …)로 남습니다.

| 파일 | 내용 |
|---|---|
| v1_첫시안.html | 첫 프로토타입: 시설 등록 → 기능 분리 → 자원 탐색 → 상속안 → 결정 |
| v2_유통망노트추가.html | 농약·농자재점 유형과 유통망 상속 노트 추가 |
| v4_시안디자인.html | 사용자 시안 디자인 적용, 5단계 분석 |
| v6_AI상담추가.html | 페이지 분리 + AI 상담(시연 모드) |
| v7_구매질문추가.html | 상담에서 구매 방법·기능상속 절차 답변 |

- v3(애플 스타일)과 v5(페이지 분리)는 v4·v6에 포함된 중간 단계라 따로 두지 않았습니다. v5 원본은 claude.ai 프로젝트에도 저장되어 있습니다.
- v8 이후(실제 지도·GPS·실시간 위치)는 Git 태그로 확인할 수 있습니다.
